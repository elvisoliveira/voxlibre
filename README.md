# VoxLibre

An independent, **offline** Android companion for the Vocci smart ring
(`com.gygeslabs.odinclient` / "Timon", Nordic nRF5340). Connects over the phone's
existing Bluetooth bond, authenticates locally, and lets you read telemetry, browse and
download recordings, play them back, and watch the raw BLE protocol — with no cloud
account required at runtime.

> [!WARNING]
> **Pairing this ring requires a key generated by Vocci's servers.**
>
> The ring's binding is gated by a per-ring secret (`BIND KEY`) and account id
> (`USER ID`) that are **minted by Vocci's backend** (`durer.proactiva.ai`) during the
> official pairing flow — they are **not** stored in the firmware and **cannot** be
> derived offline. This app does **not** pair a ring; it only talks to a ring that is
> **already bound**, using credentials you provide.
>
> **If Vocci ever shuts those servers down, a factory-reset or brand-new ring can no
> longer be paired** — by this app or the official one. A ring that is *already* bound
> keeps working with this app indefinitely (the credentials live on your device, not in
> the cloud).

## Setup

You must supply three values in **Settings** (gear icon, top-right):

| Field | What it is | Where to get it |
|---|---|---|
| **Ring (MAC)** | the ring's Bluetooth address | pick it from your phone's paired devices |
| **BIND KEY** | the 32-char per-ring secret | from the official app / your account (server-minted) |
| **USER ID** | your account id (`user_…`) | from the official app / your account |

These are **secrets** — the app stores them only in local `SharedPreferences` and they
are **never** hardcoded or shipped. Tap **Save**, then **Connect**.

> Obtaining `BIND KEY` / `USER ID` is out of scope for this repo (they come from Vocci's
> servers, tied to your logged-in account). Nothing here bypasses that.

## Features

- **Ring tab** — live status (authenticated), device info (model/SN/firmware/hardware),
  telemetry (battery, voltage, RSSI, storage), button events and 0x26 gesture monitor,
  and an optional *single-click → media Play/Pause* toggle.
- **Recordings tab** — unified list of on-ring + downloaded clips (persisted index, works
  offline), inline **download**, **play** (raw-Opus decoded on device), and delete
  (on ring / on phone).
- **Logs tab** — real-time TX/RX of the BLE protocol (timestamp, channel, opcode, hex),
  with an "unmapped interactions only" filter.

## Build

```bash
cd ring-tester
ANDROID_HOME=/path/to/android/sdk gradle :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell pm grant ai.vocci.ringtester android.permission.BLUETOOTH_CONNECT
```
Kotlin + Jetpack Compose UI over a headless Java BLE/protocol/audio core
(`RingEngine` facade → `RingProtocol` / `RingLibrary` / `RingConfig` / `RingGestures` /
`OpusAudio`, transport via the Nordic Android-BLE-Library). minSdk 31, Java 17.

## Notes

- Runs entirely on the phone's existing bond — **no cloud calls at runtime**.
- Speaks the ring's native BLE protocol and decodes its `.opus` recordings on-device.
- Interoperability project for a device you own. Not affiliated with Vocci.
